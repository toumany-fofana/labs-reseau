# Labs réseau — Cisco Packet Tracer

Maquettes d'architectures réseau d'entreprise : conception, configuration,
validation et dépannage. Chaque lab est documenté et reproductible.

## Compétences couvertes

- Adressage IPv4/IPv6 et découpage en sous-réseaux (VLSM)
- Commutation : VLAN, trunk 802.1Q, Spanning Tree, EtherChannel
- Routage : statique, inter-VLAN, OSPF
- Services : DHCP, NAT/PAT, ACL
- Sécurité de niveau 2 : port-security, DHCP snooping
- Dépannage méthodique par couche

## Structure d'un lab

Chaque dossier contient :

- `README.md` : objectif, schéma, étapes, tests de validation
- `lab.pkt` : la maquette Packet Tracer
- `configs/` : les configurations des équipements
- `images/` : schémas et captures
